
# DentiDz Pro - كيفاش تطلق الموقع أونلاين

## الطريقة السريعة (3 دقايق) - Vercel مجاني:
1. روح لـ https://vercel.com وسجل دخول بـ GitHub
2. اضغط New Project -> Upload -> ارفع المجلد هذا كامل
3. اضغط Deploy -> بعد دقيقة يعطيك رابط حقيقي مثل https://dentidz-pro.vercel.app
4. هذا الرابط تقدر تبعثو للطبيب مباشرة!

## طريقة Hostinger (اذا عندك دومين .dz):
1. ارفع الملفات لـ File Manager
2. شغل npm run build

## كيفاش تبيع للطبيب:
- انت تدخل / لوحة المالك -> تعمر معلومات الطبيب -> تولد كود
- تبعثلو الرابط + الكود في واتساب
- هو يدخل ويلقى كلش واجد
